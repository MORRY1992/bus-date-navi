## 小さく再利用する手順
1. 日付境界図は `scripts/build-content.py` の `boundary_example` とCSSの `.boundary-example/.day-strip`。図は順序を示し、時間比例のグラフではない。例のラベルと暦日/表記の区別を同時に移す。
2. 入力→結果は `.workspace` の2列/1列、結果見出しへのフォーカス、条件変更時の無効化をひと組として扱う。
3. エラーは入力欄との関連付け、aria-invalid、入力保持、エラー欄への案内と修正対象フォーカスを保つ。
4. 夜行バス比較の担当・基準SHA・保存/広告/計算条件を確認後に1経路のみ実証。色や全サイトの見た目は一括移植しない。
