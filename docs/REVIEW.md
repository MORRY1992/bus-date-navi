# AIによる10観点の仮想レビュー

2026-10-23。実在する専門家への聴取ではない。AIが同一実装を観点別に確認した記録。

| 観点 | 指摘と対応 | 残る確認 |
|---|---|---|
| UI | ネイビーと淡青、日付・曜日・午前午後を大きく表示。320pxでは補助バッジを省き主要入力を保護 | 実機の文字拡大 |
| UX | 初期値を空欄とし入力例は明示ボタンに分離。入力変更で過去結果・コピー内容を無効化 | 実利用での入力離脱 |
| アクセシビリティ | 日本語label/fieldset、エラーrole=alert、結果見出しへフォーカス。任意欄エラーでdetailsを開く。滑らかな自動スクロールを除去 | スクリーンリーダー実機・200%ズーム |
| モバイル | 390px・320pxのiframe幅で操作・表示。大きい入力とボタン。端末キーボードで区切り文字が入力できるtext型 | iPhone Safari／Android実機未検証 |
| 旅行者 | 「準備の目安」と集合時刻を区別。00〜23時は仮定を明示し、運行日・翌日表記を確定しない | 新しい予約表記への適合 |
| 日付品質 | 68件のNodeテスト、6タイムゾーン、73,414日繰り上げ。混在区切りの日付を拒否する修正を実施 | 公開ホストでの再操作 |
| SEO | 目的の明確なタイトル・説明・canonical・sitemap・robots。独自の具体例を1解説ページに集約 | 正式ホスト名確定／クロール・流入の計測 |
| 広告 | 初版はmeta・ads.txtだけ。広告の承認・実表示・収益を分離。操作を妨げない1枠候補を文書化 | 審査・同意管理・配信コード |
| セキュリティ | 依存パッケージ0。textContentで出力、予定の送信・永続保存なし、CSP/セキュリティヘッダーを準備 | 公開時のレスポンスヘッダー |
| 初心者 | 0:20と24:20の違い・購入日ではないことを説明。入力例・全消去・コピー代替を実装 | 利用者からの不明点収集 |

ブラウザーで発見した重大不具合：全消去ボタンの旧ID `reset` が `form.reset()` を隠し、入力例が動かない状態。IDを `clear-input` に変更し、入力例・全消去を再確認。検証用ファイルは公開対象から除去する。

総合：初版実装の重大な既知不具合は修正。公開・実機・広告の未確認事項を残したまま全体を「完成」とは判定しない。
